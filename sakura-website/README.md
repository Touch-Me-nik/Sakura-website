# Сайт ресторана "Сакура"

Учебный проект по веб-разработке. 

# 🛠 Как запустить проект

Для работы сайта требуется локальный сервер с поддержкой PHP и MySQL (например, Laragon, OpenServer или XAMPP).

# 1. Установка файлов
Скопируйте все файлы из этого репозитория в корневую папку вашего локального сервера (например, в `C:\laragon\www\sakura-website` или `C:\xampp\htdocs\sakura-website`).

# 2. Настройка базы данных
1. Откройте phpMyAdmin (или HeidiSQL).
2. Создайте новую базу данных с именем `sakura_db`.
3. Выберите созданную базу и нажмите кнопку **"Импорт"** (Import).
4. Выберите файл `database.sql` из этого репозитория и нажмите "Вперёд" (Go).
*(База данных создаст таблицу `bookings` автоматически).*

# 3. Запуск
Откройте в браузере адрес: `http://localhost/sakura-website/`

#  Структура проекта
- `index.php` - Главная страница
- `contacts.php` - Страница контактов с формой
- `database.sql` - Файл для импорта структуры базы данных
- `script.js` / `style.css` - Фронтенд часть
